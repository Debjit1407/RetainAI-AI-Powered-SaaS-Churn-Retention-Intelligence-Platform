# RetainAI-AI-Powered-SaaS-Churn-Retention-Intelligence-Platform
Developed an end-to-end enterprise-style SaaS analytics and AI retention intelligence platform using Python, SQL, Machine Learning, SHAP Explainability, Streamlit, Power BI, and Ollama LLMs.

• Designed and generated a synthetic SaaS customer warehouse containing users, subscriptions, usage events, support tickets, and marketing engagement datasets using Python and SQLite.

• Built SQL-based Customer 360 analytics pipelines for churn analysis, retention tracking, customer segmentation, and behavioral feature engineering.

• Performed exploratory data analysis (EDA) and feature engineering using Pandas, NumPy, Matplotlib, and Seaborn to identify churn patterns and customer engagement trends.

• Developed churn prediction models using Logistic Regression, Decision Trees, Random Forest, and XGBoost with evaluation using ROC-AUC, Precision, Recall, F1-score, and Confusion Matrix.

• Implemented Explainable AI using SHAP to analyze global and customer-level churn drivers for transparent AI decision-making.

• Integrated Ollama LLM (Phi-3) to generate AI-powered churn explanations, executive summaries, and retention recommendations.

• Built an interactive Streamlit application featuring executive KPI dashboards, customer intelligence lookup, churn analytics, and AI-generated retention insights.

• Created Power BI executive dashboards with churn KPIs, plan-wise churn analysis, country-wise segmentation, and industry-level retention analytics for business storytelling and decision intelligence.

• Applied modular enterprise project architecture with virtual environments, reusable pipelines, SQL warehouse design, and production-style folder structure.
